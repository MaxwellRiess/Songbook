Songbook clipper for iPhone

iOS cannot run the browser extension, so the same reader runs inside a Shortcut instead. Set this up once and clipping becomes a share sheet tap.

1. Copy the clipper script

About 22 KB of JavaScript.

2. Build the Shortcut

  1. Open Shortcuts and tap + to make a new one.
  2. Tap Info (ⓘ) and turn on Show in Share Sheet.
  3. Under Share Sheet Types, leave Safari web pages on and turn everything else off.
  4. Add the action Run JavaScript on Web Page. Select all of its placeholder text and paste the script over it.
  5. Add an If action. Set its input to Dictionary Value → key error from the JavaScript result, and the condition to has any value.
  6. Inside the If branch, add Show Alert with that same dictionary value.
  7. In the Otherwise branch, add Open URLs with Dictionary Value → key url.
  8. Name it Clip to Songbook and save.

3. Use it

  1. Open a song on Ultimate Guitar or GuitarTuna in Safari and let it load.
  2. Tap Share, then Clip to Songbook.
  3. Allow the script to run when iOS asks. It asks once per site.
  4. Songbook opens and shows Clipped song imported.

Worth knowing

The Shortcut has to run from Safari. Other iOS browsers do not offer Run JavaScript on Web Page.

A home screen web app keeps its own storage, separate from Safari's. The clip lands in the Safari copy of Songbook, so sign in to Supabase sync there as well and the song will reach your installed copy on its next sync.

Clipping into a local development copy means editing SONGBOOK_URL at the top of the script before pasting it.
